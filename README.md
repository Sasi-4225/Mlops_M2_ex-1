# MLOps Experiment 1 - First CI Pipeline

This experiment demonstrates a basic Continuous Integration (CI) pipeline using GitHub Actions.

## Flow
Code Change -> Commit -> GitHub -> Hosted Runner -> Python 3.11 -> Unit Tests -> PASS/FAIL

## Test Cases
- 70 marks, 85% attendance -> PASS
- 30 marks, 85% attendance -> FAIL
- 70 marks, 60% attendance -> FAIL
